# Virginia Forge
Free public index: Thomas Jefferson's 23 drawings for Richmond (1779–1809), laid out together as a puzzle map. Each piece links to its original at the Massachusetts Historical Society (Coolidge Collection of Thomas Jefferson Manuscripts; public domain, credit MHS). No sign-in, no payment, no database.
